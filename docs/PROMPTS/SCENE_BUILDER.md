# 单场景资产与玩法生成 Prompt

读取目标 ID 的 `production/scene_plan.json` 记录及场景 canon，先提供：玩家进入/看见/操作/受到回应/危险变化/离开的6步概述。为每一步列机位高度、动线、声源、光源和事件因果。先在线检索3–5项不同的现实建筑/道具参考，注明来源与授权范围，禁止一比一复刻或把参考图作为贴图。

输出：① blockout .blend与.glb(如可实际制作) ②工程可导入目标路径与版本 ③对象资产清单、UV/法线/碰撞清单 ④三视角真实截图 ⑤让独立玩家知道目标的可操作提示 ⑥失败/恢复交互逻辑 ⑦性能与版权风险 ⑧独立审查任务卡。

如果缺少Blender/UE，只能写出脚本并明确环境阻断。不得只生成“电影感/恐怖/高清”等泛化描述；每个道具说明现实制造与使用理由。禁止额外增加角色秘密和世界观反转。
