# 世界观手册 + 原创剧本初稿 v0.2

本文件是实际制作剧本，优先人物、物证和行为因果；哲学仅通过道具系统暗示。所有城市、机构、人物均为虚构。

## 世界成立的基本事实（玩家可在主线得知）
1. 临汐是气候潮湿的港城。城市曾设立“回执局”，为领取困难的文件、照片、民政通知与申诉副本保留纸质备份。
2. 新系统 R-Array 将查询、催办、拒收、延期、修正这些状态转化成可追踪的工作流程；节省了人力，也产生过误判。
3. 一位职员提出：查询人的意向，不代表这个人愿意继续查询。系统却把每一次查看记录的行为视为新的同意。
4. 机构争议后被停用。离线机柜在停机时仍然出现记录数量增加，但这不能被自动解释为任何确证的超自然规律。
5. 本夜的主线任务是取回一个实体数据匣，使外部调查至少拥有可核实的证据。

## 四个角色的行动而不是标签
**复核员21（玩家）**：工作是确认“哪一项活动被实际执行了”。TA不是救世主，也不是哲学演讲人。档案局内经历会改变其执行一项请求的方式，但结局不等于“彻底摆脱思考”。

**林澈**：声音平静，却不断在各份文件上更正同一个日期。她犯过可调查的具体错误：批准了不带人工复核的自动补发。最后留下正确关闭系统的电路标示。她不会作为怪物突然现身。

**罗衍**：工程师。他曾相信所有未完成请求都可以由机器继续跟进，但后来意识到系统将“知道自己正在被查询”也当成可执行状态。他留下了一项物理切断方案。玩家最后通过这项有代价的方案获得有限成功。

**巡查员**：敌对者并非“罪恶本身”。他（或它）反复运送一个空的资料箱，身体行动服从一种已经没有收件人的流程。行动有物理约束：能听声音，会被门挡住，会在失去目标后搜索最后位置。绝不全知瞬移。

## 关键场景具体文字（短，不让玩家阅读小说）
### 第0幕 / 前台
门外工单：
> 工单 21-47。夜间移交：R-Array 离线数据匣一件。进入后沿维修标线走，禁止恢复自动补发功能。接收地点：地面登记窗。

前台告示：
> 未领取的照片保管三十日。如申请人要求销毁，请在背面签字。空白栏不视作同意。

录音机中第一次出现林澈（内容短、自然、不带哲学名词）：
> “罗工，四楼又自己亮灯了。你上次说拔掉总线就行，我照做了。现在下面还在打字。”

玩家拿到工号卡时，电话响一次。接听只听到拨号静音；挂断后铃声从走廊另一端响起。玩家有离开或追查的自由，但主路仍清晰。

### 第I幕 / 呼吸登记处
设备标记“低压安全 / 高压登记”。压阀过程中气压表滞后，旁边有带顺序的磨损图例。错序无伤害：系统自动泄压再试。玩家第一次成功后，柜中纸条弹出一张与主角刚刚操作时间吻合的新记录。

林澈录音：
> “别写‘请求人拒绝’。他只是说晚点回来。我们又不知道他会不会回来。”

### 第II幕 / 两次答复
画面第一次看到巡查员背着空文件箱走过通道。角色动作慢，但步伐有可预测的机械节奏。安全潜行区域是一处能掀开挡板的记录室，不是任意一个黑暗角落。

屏幕上只写“未签收”，旁边真实手写：“系统又写成拒收了。”玩家获取门禁钥匙，拿起钥匙时触发可逃脱追逐，巡查员奔向档案出口。

### 第III幕 / 观察实验层
装置有一面真正的单向玻璃、两条延时灯线和可旋转反射板。谜题是对准灯和读取延迟时间，不是用“看见自己”等诗句猜密码。

罗衍维修日志：
> “第三次检查仍然显示待检查。我查了日志，检查记录本身又变成了新的待办。明天必须改逻辑。”

### 第IV幕 / 坐标档案馆
局部开放三个区：申诉档案、样片柜、机房。玩家自由选择顺序取三项零件/资料完成主线。额外文件记录几位普通人：有人忘记领照片，有人主动撤回请求，有人只是刚好搬家。系统却把三人归到同一类。

中心机柜的工作牌：
> “记录不能替申请人作决定。”

### 第V幕 / 最后一张回执
罗衍最后语音：
> “我能让它停一阵。它会把停机申请继续登记，但断了供电，至少不会再有人照着这张单子去敲门。你把硬盘拿出去。”

玩家执行具体三步：手动脱离远程供电—旋开数据匣—打开物理防火门。此时系统打印出“复核停机之申请：待复核”。不提示玩家哲学答案，也不让角色突然明白全部宇宙规则。

尾声：正常城市街道的清晨，公交站牌显示下一班还有5分钟，手机收到一个与工作无关的普通消息。玩家可以结束游戏，或在结算页检查自愿收集的资料。建筑内部有一声极轻的打字声，画面切黑。

## 收藏分层的具体写法
- 人物回执（8）写真实生活细节，与“欲望无穷”无关，提供人的丰富性。
- 维修谱（6）写设施实际可预测的规则，奖励愿意推理的玩家。
- 录音残片（5）允许更文学化，但不能代替主线目标。

## 导演目标
主角必须在游戏里取得一个具体成果：把证据带出去。观众可以不认同游戏的哲学，但必须能讲清：谁委托了什么、哪个机器错了、为什么要查、为什么要跑、最后带走了什么。
