# 私人思想到虚构玩法的转换规范

**设计方法**：只吸收非可识别的认知与行为形式，不用现实亲友姓名、疾病、家庭冲突、迁移身份、实际履历或私人照片。玩家不是创作者的模拟人格，叙事不能在游戏内暗示创作者本人患某种疾病。

| 思想/体验母题（从长期对话提炼） | 虚构转译 | 作品中可观察的作用 |
|---|---|---|
| 无法把轻微请求自然推进到下一步 | 未领取的工单与待确认的照片 | 玩家实际通过柜台机制取得钥匙而非朗诵反思 |
| 每增加一点行动成本便审查需求是否合理 | 门禁需要少量回程操作 | 只要真实的短回程，不故意折磨玩家 |
| 反思可以反馈成为反思对象 | R-Array 将检查操作记为下一条检查任务 | 空间更新与主线实体故障有因果联系 |
| 对未知隔绝空间好奇又因预期而犹豫 | 可信的广播/脚步预兆 | 长时低压迫到短时明确危险的节奏转化 |
| 一种体验可以痛苦或轻松但结构属性相同 | 平静办公室与焦躁档案室具有相同机械记录结构 | 避免把“罪恶”映射为红屏或角色心跳值 |
| 对意识连续性、重新认识他人很敏感 | 旧档案中同一请求被反复错误归类 | 让玩家区别系统标签与真实的人 |
| 希望私人思想史长期保存和能被研究 | 主线收集的维修谱与人物回执 | 选择性取证比全量打卡重要 |

**三条禁止**：不把私密创伤变成跳脸镜头；不把个人精神状态转化为“主角发疯”俗套；不把“用户哲学理论”写成对玩家的必须信仰。
