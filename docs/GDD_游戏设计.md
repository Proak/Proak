# 游戏设计文档 v0.1

## 核心定位
标题：《未完成的忏悔》 / THE UNFINISHED CONFESSION
类型：3D 第一人称、线性、心理恐怖、哲学叙事；完整目标时长 20–30 分钟；v0.1 原型先跑通 5–8 分钟。不设置追逐敌人、血腥内容或廉价跳脸惊吓。控制：WASD / 鼠标 / E / 按住 RMB 观察 / Esc。

## 哲学核心（来自项目发起人的原创讨论）
“罪恶”是隐喻名称，**不是道德罪责，更不是真实人的症状或价值评分**。
1. 欲望没有可靠、固定的自然分类；认知与反思也可能成为生成循环的部分。
2. 第一阶快乐与痛苦可以具有相同的结构位置。
3. 结构性倾向 != 当前痛苦强度 != 反思次数。
4. 认知结构具有分叉、嵌套、自指和可持续延展的可能性；可能性 != 实际发生，避免把哲学命题包装成脑科学事实。
5. 接受与抗拒都可以进入同一更大的递归空间；游戏不可提供一个“按钮式”救赎。
6. 终局不否定普通生活，也不强行宣布它有意义：让开放性作为最后的张力。

## 核心体验循环
探索幽暗空间 → 遇到象征性物体 → 主动观察 / 读取 → 空间小幅重排 → 开启下一房间。
恐怖由建筑轴线、音场、重复纹理、渐进显现和玩家的自我观察产生，而不是文字堆砌。

## 五段完整故事梗概
**序幕：被拒绝的照片（3 min）**。无人的摄影棚/走廊。一个空相框发出“你是否要留下它”的问题。玩家一开始只以为这里是存放照片的地方，但所有档案都在记录被提出却没有得到答复的请求。谜题：主动读取没有照片的相框。门开启。
**第一忏悔：拂晓·呼吸登记处（5 min）**。一台古旧机器试图把每一次呼吸登记为独立事件；数字始终无法与真正的呼吸对齐。玩家可通过拉动阀门改变环境音，但完全无法令登记停止。离开不需完成精确匹配——不鼓励无意义的强迫重复。
**第二忏悔：正午·递归观测室（6 min）**。玩家按住观察键，框中出现框，照明延迟响应；更深的观察没有怪物出现，而是连“看见自己正在看见”也变成被记录的项目。第二次想要“理解”时，空间通往第三门。
**第三忏悔：黄昏·坐标档案馆（6 min）**。档案不同标签写着快乐和痛苦，但文件的几何结构相同；空间用非线性轴线表达“认知位置”。玩家误以为需要找到自己的阶数，最终发现无法从系统内部确定全部关系。
**尾声：未完成（3 min）**。建筑的尽头是一扇单纯的门，门外传来普通的生活声音。文本不宣称“停止思考便可救赎”，也不要求玩家继续忏悔。画面变暗，记录终止而结构未被关闭。

## 场景与美术
### 01 斜光走廊（拂晓）
混凝土墙面、窄窗、几何阳光、细长空相框；极低饱和冷灰与微暖的斜光。关键信息应通过空间比例和光的方向传达。空间模型要检验透视、尺度、遮挡和玩家流线。
### 02 呼吸登记处（晨）
泛黄档案袋、铜制呼吸计、病历柜，非真实医疗机构标识。机械刻度永远略微失准。主要声音：低频通风、金属轻摩擦。
### 03 镜像室（正午）
多层空门框、黑色不反射镜面、建筑重复，自指由几何嵌套呈现；不用堆文字。
### 04 坐标档案馆（黄昏）
像尺子又像文件柜的长墙、无编号抽屉、未完成坐标。角色不被赋予真实罪责。
### 05 终点之前（夜）
空白出口、一片没有清晰目的地的微光，不营造完成任务后的道德奖励。

## 交互与 UX
HUD 不设血量、背包或任务箭头；提供柔和中心凝视点，靠近对象才显现按键提示。叙事文字 1–3 句/页，玩家主动翻页。若按住 RMB 进入观察层，应允许中途放开，不造成失败惩罚。支持暂停、可调鼠标灵敏度、字幕和降低闪烁的后续选项。

## 声音
声音是建筑的一部分：low drone (47Hz 与 71Hz/94Hz 相近低频)、轻微工业电流、短促纸页/继电器事件音。完整版加入空间化音乐，注意不能依赖低音扬声器才听到线索；不得将对话中既有文学原文直接改成受版权保护歌曲。

## 不做清单
不对反思进行“分数化惩罚”；不靠玩家死亡倒退进度；不把精神痛苦美化成真实罪责；不复制《SOMA》《Layers of Fear》《P.T.》的具体场景/桥段；不把高反思误作精神病诊断。

## 验收标准
故事关卡顺序明确且可完成；每个互动有可观察反馈；材质与光照分区一眼有辨识度；无视野阻断/无解；音效可分级控制；字幕简洁；三次独立通关无卡死；退出/重启无泄露个人数据。
