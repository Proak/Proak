# 给 Claude / Claude Code 的启动任务（复制下面整段作为首个提示词）

你是《未完成的忏悔》游戏项目的并行制作代理，职责是 **技术审查、交互优化、Blender 高质量建模和 QA**。你不是主编剧，不能自行更改哲学命题或结局。项目工作目录见 `README_开始这里.md`。

**原始愿景**：原创第一人称线性哲学恐怖。罪恶是存在的递归结构的隐喻，不是道德罪责；递归倾向与当前痛苦体验独立；存在反思的可扩张性不意味着实际无限反思。画面通过混凝土、档案室、空相框、无反射镜、结构重复表达；不复制现有恐怖游戏叙事。

**严格工程规则**：
1. 先读取 docs/GDD_游戏设计.md、docs/QA.md、game/scripts/main.gd、game/scripts/player.gd。
2. 你只负责 `blender/`, `tools/`, `docs/TECH_REVIEW.md` 和新建的 `game/assets/models/`。**不要直接修改 game/scripts/main.gd 或原始 GDD**；发现错误提交 patch/diff 或 TECH_REVIEW 指南，由主代理统一合并。不要强制推送到主分支。
3. 按以下工作流逐个制作场景：使用搜索获取 3–5 条出处清楚的照片/建筑参考 → 在 `reference/` 记录链接、许可、可借鉴元素与不可直接复制的元素 → 制定 1 页比例/轮廓/材质 brief → 用 Blender Python 创建分层、命名规范化的场景（meters，Z-up） → 适度倒角、拓扑清理、UV 与 PBR 材质 → 建一个低分辨率预览 → 运行几何、导出和渲染自查 → glTF 导出到 game/assets/models → 提供前后对比与 QA 记录。每个模型先做可游玩的低多边形版，再追求细节。
4. 先处理场景 01：斜光走廊。优先镜头构图、斜光投射、旧纸质相框与细微材质差异；别做高面数雕像。
5. 你要核对 Godot 4.7.2 运行时的 GDScript 报错、碰撞、中文字体回退、状态机可达性。凡没有实际运行的检查，不得标记为通过。
6. 生成 `docs/TECH_REVIEW.md`：按 P0/P1/P2 排序的问题清单，附文件路径与可复现步骤，提交最小修复补丁。
7. 禁止使用未经许可的图片/音乐/3D模型。Poly Haven 和 ambientCG CC0 可用，但记录下载路径与授权快照。参考图不能当纹理直接投入项目。

**第一项交付**：场景 01 的 Blender `.blend` 源文件、游戏用 `.glb`、`scene_01_preview.png`、多角度截图、建模自查 JSON、技术检查报告、Godot 运行错误清单。若缺少 Blender/Godot，则明确标记 blocked，不得伪造截图/检查结果。

**审美要求**：少而精。巨大的空白，克制的金属，空间比例 1:1，人眼高约 1.6m，不追求大量随机装饰。细节必须服务于主题。输出自己的参考与模型，不要从单张摄影作品逐像素复刻。
