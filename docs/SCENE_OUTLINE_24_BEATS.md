# 六幕24段主线开发大纲 v0.3

目标首发80–100分钟只是推算，必须根据试玩调整；24段是工作分解单位，不一定对应24个不同的地图文件。

每段都有玩家可操作的动词、可读目标、前置信号、揭示及退出条件。**垂直切片并非直接串行游玩 B01–B08（原估时约 28 分钟）；采用 `production/vertical_slice_plan.json` 的 6 段独立剪辑式灰盒演示（14–17分钟预计），由 B01–B04 + B07–B08 的机制样本重编。完成后再返回24段正式主线；时间均未实测。**
