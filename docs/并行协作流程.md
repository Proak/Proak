# ChatGPT + Claude 并行协作约定

## 两个独立角色
ChatGPT（主设计/集成）：剧情结构、Godot 主程序、UI/音频调性、统一世界观、质量门禁和合并。
Claude（美术/审查）：参考调研、Blender 建模与导出、技术审查、游戏可玩性/可读性建议。两者都需要用户主动运行各自工具；在本聊天无法直接启动 Claude 会话。

## 推荐目录/分支
`main` —— 仅放通过检查的版本；`chatgpt/gameplay-v01` —— 玩法与 UI；`claude/art-scene01` —— Blender/glb 与校验。改动通过 PR/code review 合并，不要同时直接覆盖同名文件。

## 每场景审查七关
G0 参考研究：记录原始出处/许可、不可直接复制的元素。
G1 概念：确认构图、叙事意图与交互。
G2 灰盒：标出玩家路线、视线与交互安全距离。
G3 Blender：应用缩放、尺度(米)、命名、材质、UV/拓扑清理。
G4 预览：三机位渲染（入口/中景/交互近景），灯光和轮廓必须清晰。
G5 运行：Godot 导入、材质/碰撞、FPS/内存、实际互动完整性。
G6 复审：盲测反馈、修正清单、回滚策略。不得跳过 G4/G5 却宣称已完成。

## 文件交接契约
models/<scene_name>.glb，原始 .blend；`reference/scene_XX.yaml` 记录 source/license/usage；`qa/scene_XX.json` 记录实际检验内容；`docs/TECH_REVIEW.md` 记录阻断事项。
