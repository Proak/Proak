# 素材权利、原创、发行审查

商用的每一个外部资产：来源URL、创作者、授权文本及日期、使用范围、署名义务、限制（编辑/游戏分发/AI训练）、修改记录、最终文件hash。参考图不等于可复用资产。不确定版权则**不进入最终仓库**，使用占位原创几何体替代。

不可依靠“免费”二字判断可商用。CC0、CC-BY、平台单独EULA、音乐表演/录音版权必须分别核实。Poly Haven的资源可按其明确CC0使用，但下载时仍记录资产URL与许可快照。不得复制某个知名恐怖作品的独特敌人/镜头/音乐。

AI生成内容的发行披露依实际内容和平台现行政策真实填写；去AI味是去除模板化和提升质量，而非隐瞒AI参与。最终收尾：素材清单、授权证据、字幕/多语言、音量/闪烁设置、故障报告、真实构建hash、玩家反馈、商店素材许可。
