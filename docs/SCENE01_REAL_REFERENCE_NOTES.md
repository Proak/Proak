# L0_B01 回执局门厅：首轮实物建筑参考（2026-11-01）

以下均是**外部视觉参考，未加入项目美术资产，绝不直接复制摄影作品或现实建筑布局**。

1. [Boston City Hall lobby renovation](https://www.utiledesign.com/work/boston-city-hall-lobby-renovation/)：公用建筑服务台与闸机动线；可学习“公民办事服务台可读性”，不能复制柜台造型。
2. [Oberwil Gemeindehaus](https://www.bfbag.ch/blog/2023/oberwil-gemeindehaus)：顶光混凝土结构与温润木质前台的对照；用于照明/材料情绪，不得复刻建筑。
3. [WSP National Archives](https://www.wsp.com/en-au/projects/national-archives)：移动档案柜的真实滚轮/手柄/走道设计；用于物理逻辑与后续档案楼层延展。
4. [Smithsonian 1880 archival shelving — CC0](https://siarchives.si.edu/collections/siris_arc_388196)：蜂巢式存储格的历史功能逻辑；来源注明CC0，但本阶段仅作为设计参考。

## 本场景审美决定（设计提案，不是完成图）
- 现状应为**仍正常工作的公共设施，只是夜间空无一人**；不要一开始就用遍地残骸、浓雾和血污暗示恐怖。
- 入门最远目视点为地下室维修门；左侧正常服务台、右侧封闭档案接收窗；主光来自雨后傍晚偏侧高窗，声音来自电力管道。
- 摄影证据要求：从入门右偏、柜台前侧、二次返回这三机位截真实引擎图；未安装 Unreal 时全部 BLOCKED。

灰盒实机移动/开柜台/取得工作证/打开地下维修门，在镜头中辨认玩家目标，测试无文字玩家是否仍找到门禁。不通过则重设计动线，不进入高模制作。
